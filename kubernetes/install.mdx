---
title: "安装 Kubernetes"
description: "在本地或云端搭建 Kubernetes 集群"
---

根据你的场景选择合适的安装方式。

## 本地开发环境

适合学习和本地调试:

- **minikube**:在虚拟机或容器中运行单节点集群,官方入门工具
- **kind**:使用 Docker 容器运行节点,启动快,常用于 CI
- **Docker Desktop**:勾选设置里的 "Enable Kubernetes" 即可

以 minikube 为例:

```bash
brew install minikube
minikube start
kubectl get nodes
```

## 生产环境

- **云厂商托管集群**:GKE、EKS、AKS 或 ACK,控制平面由云厂商维护
- **kubeadm**:官方提供的裸机集群引导工具,适合自建机房

<Tip>
  学习阶段推荐先用 minikube 或 kind,熟悉概念后再接触生产级安装。
</Tip>

## 验证安装

```bash
kubectl cluster-info
kubectl get pods --all-namespaces
```

能看到控制平面组件的 Pod 处于 Running 状态,说明集群可用了。
