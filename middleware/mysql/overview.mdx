MySQL 是最常用的开源关系型数据库,承担事务型业务数据的存储。本小节整理它的部署、使用与运维实践。

## 核心概念速览

| 概念 | 说明 |
| ---- | ---- |
| 库 / 表 | 数据的两级组织单位 |
| 索引 | 加速查询的 B+ 树结构,不是越多越好 |
| 事务 | ACID,InnoDB 默认隔离级别是可重复读(RR) |
| 锁 | 行锁、间隙锁、表锁,死锁排查是日常 |
|  redo / binlog | 崩溃恢复与主从复制的日志基础 |

## 典型使用场景

- 业务系统主库:订单、账户、库存等强一致数据
- 配合 [Redis](/middleware/redis/overview) 做缓存,减轻读压力
- 慢查询与连接数是最常见的两类性能瓶颈

## 运维重点

- **备份恢复**:`mysqldump` 逻辑备份、XtraBackup 物理备份
- **高可用**:主从复制、半同步、MHA / Orchestrator
- **性能**:慢查询日志、`EXPLAIN` 执行计划、索引优化
