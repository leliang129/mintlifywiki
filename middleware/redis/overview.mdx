Redis 是基于内存的键值数据库,以微秒级延迟承担缓存、计数、锁等高频读写场景。本小节整理它的部署、使用与运维实践。

## 核心数据结构

| 结构 | 典型用途 |
| ---- | ---- |
| String | 缓存对象、计数器、分布式锁 |
| Hash | 对象字段级缓存 |
| List | 简单消息队列、最新列表 |
| Set | 去重、交集并集(共同关注) |
| ZSet | 排行榜、延迟队列 |

## 典型使用场景

- **缓存**:挡在 [MySQL](/middleware/mysql/overview) 前面,注意缓存穿透、击穿、雪崩三兄弟
- **分布式锁**:`SET NX PX` 加锁,Redisson 看门狗续期
- **会话与限流**:Session 共享、滑动窗口限流

## 运维重点

- **持久化**:RDB 快照与 AOF 日志的选择与混合使用
- **内存**:maxmemory 与淘汰策略(LRU / LFU)
- **高可用**:主从 + 哨兵,或 Cluster 分片集群
- **大 Key 与热 Key**:线上事故的高发区,靠监控与扫描发现
