自动化运维的目标:把重复的部署、配置、巡检工作交给工具,人只做决策。本栏目按分工整理三类核心工具。

## 工具分工

| 领域 | 代表组件 | 解决什么 |
| ---- | ---- | ---- |
| 基础设施即代码 | Terraform | 声明式创建云资源:主机、网络、K8s 集群 |
| 配置管理 | Ansible | 无 Agent 批量配置:装软件、改参数、管服务 |
| 巡检与 SOP | Python 脚本 | 定制工具:巡检报告、API 编排、定时任务 |

三者的典型协作顺序:**Terraform 把资源建出来 → Ansible 把系统配好 → Python 补上定制化工具**。发布流水线的内容归 [CI/CD & GitOps](/cicd/overview) 栏目。

## 推荐阅读顺序

<Steps>
  <Step title="Ansible">
    先学[ Ansible 概述](/automation/ansible/overview):批量配置管理是日常运维最高频的自动化需求。
  </Step>
  <Step title="Terraform">
    再学[ Terraform 概述](/automation/terraform/overview):把基础设施也纳入代码管理,环境可复制。
  </Step>
  <Step title="Python">
    最后用[ Python 概述](/automation/python/overview)补齐定制能力:巡检、报告、内部小工具。
  </Step>
</Steps>
